# Tipografía institucional (Circe Rounded)

Circe Rounded tiene **licencia comercial**, por eso los archivos no están en
el repositorio. Copia aquí los dos archivos que entrega el área de diseño:

- `CirceRounded-Medium.otf` (textos)
- `CirceRounded-Bold.otf` (títulos)

Después ejecuta `npm run build` (o reinicia `npm run dev`). Sin estos archivos
el proyecto funciona igual, pero usa la fuente del sistema.
